# massgainer
Diario de fuerza: PWA sin dependencias para apuntar los entrenamientos.

## Biblioteca de ejercicios
`ejercicios.js` tiene los ejercicios que se pueden hacer con el material de casa (mancuernas, kettlebell, polea, barra y peso corporal), con músculos, técnica en español y fotos en `ex/`.
Las fotos y los músculos vienen de [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público), reducidas a 360 px.
